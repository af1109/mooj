# Part 1: Cold prompt

**Status: no authentic cold-prompt version exists in this project.**
The prototype was built from a detailed specification, not from the assignment's deliberately vague prompt,
so it must not be presented as the cold-prompt result. If you have your own original cold-prompt screen,
keep it separately and add it here.

## Usability risks to look for in a vague-prompt club screen (hypotheses, not test results)
- Unclear first action: several equal-weight buttons and no single obvious "start".
- Too much information on the first screen (prices, schedules, pools, marketing) before a task starts.
- Confusing navigation: seasons, periods and shifts mixed in one list, or a menu that hides registration.
- Difficulty starting registration: the form appears before choosing season / period / shift.

How the final prototype addresses them by design (still to be confirmed by a real tester):
one primary button ("يلا نبدأ التسجيل") on the hero, a 6-step progress indicator, one decision per section.
